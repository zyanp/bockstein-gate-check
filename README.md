# bockstein-gate-check

CSS 符号における横断的（transversal）対角ゲートの実装可否を判定する最小プロトタイプ。
arXiv:2602.14499（J. Haruna, "Homological origin of transversal implementability of logical diagonal gates in quantum CSS codes"）の判定原理を、既知の小規模符号で数値的に裏付けるためのもの（科研費申請の裏付け資料）。

純 Python・外部依存なし。

## 判定原理

CSS 符号（X 検査行列 H_X、Z 検査行列 H_Z、H_X H_Z^T = 0）に対し、レベル m の横断的対角ゲート

U(θ) = ⊗_j diag(1, ω^{θ_j}),  ω = exp(2πi/2^m),  θ ∈ (Z_{2^m})^n（非一様角度可）

を考える。符号語は |x̄⟩ = Σ_{s∈rowspan(H_X)} |l⊕s⟩（l は論理類代表 ∈ ker H_Z）。
U は対角なので、U が符号空間を保ち対角論理作用を与えることは、各論理類の上で位相
Σ_j θ_j y_j mod 2^m（y は GF(2) ベクトルの整数持ち上げ）が一定であることと同値。
整数持ち上げ (l⊕s)_j = l_j + s_j − 2 l_j s_j を使うと、この一定性は Z_{2^m} 上の線形合同式系

Σ_j θ_j s_j (1 − 2 l_j) ≡ 0 (mod 2^m)  （全論理類代表 l、全 s ∈ rowspan(H_X)）

に帰着する。s ↦ 持ち上げは GF(2) 上で非線形なので **rowspan(H_X) の全 2^{r_X} 元を列挙**して条件を張る（生成元だけでは不十分）。論理類代表も全 2^k 類を回す。

解集合は、制約行列（成分 ∈ {−1,0,+1}）の整数対角化（Smith 標準形型の行・列基本変形）で厳密に求める（θ の総当たりはしない）。解 θ に対する論理位相は φ(l) = Σ_j θ_j l_j mod 2^m（解の上では代表の取り方によらない）。

**判定**: 「真にレベル m の対角論理ゲート（m=2 で論理 S、m=3 で論理 T、の奇数冪）が存在する」⟺ ある非自明論理類で φ が奇数になる解 θ が存在する。解モジュールの生成元での φ の値の gcd（と 2^m の gcd）が 1 かどうかで判定する。gcd = 2^ν なら、レベル m で達成できる論理位相は 2^ν の倍数のみ（= 実質レベル m−ν のゲートまでしか出せない）。

arXiv:2602.14499 との関係: 論文はこの可否を持ち上げ（lifting）問題の障害写像（Bockstein 型準同型）の消滅として特徴づける（Thm IV.1 / Cor IV.2）。本プロトタイプは同じ可否を「論理性条件を直接 Z_{2^m} 上の線形合同式系として解く」直接判定で実装したもので、論文の各レベルでの判定（ガウス消去 / Smith 標準形で具体的に判定可能、という主張）の最小実装にあたる。

## ファイル

- `bockstein_check.py` — 判定本体（GF(2) 線形代数、整数対角化、mod 2^m 同次系ソルバ、`analyze`、総当たり検証 `verify_theta`）
- `codes.py` — 3 符号の定義と自己検査（H_X H_Z^T = 0、[[n,k,d]] を全列挙で検証）
- `test_known.py` — 既知事実との照合テスト（PASS/FAIL 出力、失敗時 exit 1）

## 実行方法

```
python codes.py        # 符号の自己検査のみ
python test_known.py   # 判定＋既知事実テスト（結果表を表示）
```

## 結果（2026-08-11 実行、全テスト PASS、総計算時間 0.02 秒）

| 符号 | ゲート | 可否 | 達成可能な論理位相の部分群 | 例 θ |
|---|---|---|---|---|
| Steane [[7,1,3]] | Z (m=1) | **可** | Z_2 全体 | 論理 X 台上の 1 |
| Steane [[7,1,3]] | S (m=2) | **可** | Z_4 全体 | [1,1,3,1,3,3,1] |
| Steane [[7,1,3]] | T (m=3) | **不可** | 2·Z_8（偶数のみ） | — |
| Reed–Muller [[15,1,3]] | S (m=2) | **可** | Z_4 全体 | [1,1,3,3,1,1,3,0,…,0] |
| Reed–Muller [[15,1,3]] | T (m=3) | **可** | Z_8 全体 | [1,1,7,1,7,7,1,1,7,7,1,7,1,1,7] |
| 回転表面符号 [[9,1,3]] | S (m=2) | **不可** | 2·Z_4（論理 Z のみ） | — |
| 回転表面符号 [[9,1,3]] | T (m=3) | **不可** | 4·Z_8（論理 Z のみ） | — |

既知事実との照合（すべて再現）:

- **Steane: 横断的 S 可・横断的 T 不可**（arXiv:2602.14499 Cor V.1 の再現）。T 不可は**非一様角度を許しても**成立（レベル 3 の解の論理位相がすべて偶数 = 2·Z_8）。さらに θ = 3·1_7（各量子ビットに S†）が論理 S になることを総当たり検証で確認（Cor V.1 の具体解と一致）。
- **RM [[15,1,3]]: 横断的 T 可**。θ = 1_15（各量子ビットに T）で論理位相 7 mod 8（= 論理 T†）を総当たり検証で確認（古典的既知事実と一致）。
- **回転表面符号: 横断的 T 不可**（既知）。**横断的 S も不可**（達成可能位相は 2·Z_4、すなわち論理 Z まで）。申請調書・図 4 の主張「回転表面符号では横断的 S 不可」を裏付ける。

副次的観察: Steane のレベル 3 の位相部分群が 2·Z_8 であることは「レベル 3 の横断的ゲートで出せるのは高々論理 S（ω_8^2 = i）まで」を意味し、レベル 2→3 の持ち上げ障害（論文の β 写像）の非消滅と整合する。

## 実装上の注意（理論の解釈で仮定した点）

1. 「横断的対角ゲート」は単一量子ビット対角ゲートのテンソル積 U(θ) = ⊗_j diag(1, ω^{θ_j}) に限定（論文の設定と同じ。CZ 等の多体対角は対象外）。
2. 「レベル m のゲートが存在する」の判定基準は「ある非自明論理類の論理位相 φ が奇数になる解の存在」とした（φ が偶数のみなら ω^φ はより粗いレベルで実現できるため）。k=1 の 3 符号では非自明類は 1 つ。
3. 論理類の代表 l の取り方に判定は依存しない（一定性条件の下で φ(l⊕s) = φ(l) となることを解の検証 assert で確認済み）。
4. 制約は生成元でなく rowspan(H_X) の全元・全論理類で張った（持ち上げの非線形性 (a⊕b) = a + b − 2ab のため。2^{r_X} ≤ 16 なので全列挙で厳密）。
5. 可と判定した場合は必ず、返された例 θ を線形代数を使わない総当たり位相列挙（`verify_theta`）で独立に検証している。
