# bockstein-gate-check

CSS 符号における横断的（transversal）対角ゲートの実装可否を判定する最小プロトタイプ。
arXiv:2602.14499（J. Haruna, "Homological origin of transversal implementability of logical diagonal gates in quantum CSS codes"）の判定原理の最小リファレンス実装で、既知の小規模符号に対して判定を数値的に検証する。

純 Python・外部依存なし。

## 判定原理

CSS 符号（X 検査行列 $`H_X`$、Z 検査行列 $`H_Z`$、$`H_X H_Z^{\mathsf{T}} = 0`$）に対し、レベル $`m`$ の横断的対角ゲート

$$U(\theta) = \bigotimes_j \mathrm{diag}\bigl(1,\ \omega^{\theta_j}\bigr),\qquad \omega = e^{2\pi i/2^m},\qquad \theta \in (\mathbb{Z}_{2^m})^n$$

を考える（角度 $`\theta_j`$ は非一様でよい）。
符号語は $`|\bar{x}\rangle = \sum_{s\in\mathrm{rowspan}(H_X)} |l\oplus s\rangle`$（$`l`$ は論理類代表 $`\in \ker H_Z`$）。
$`U`$ は対角なので、$`U`$ が符号空間を保ち対角論理作用を与えることは、各論理類の上で位相 $`\sum_j \theta_j y_j \bmod 2^m`$（$`y`$ は GF(2) ベクトルの整数持ち上げ）が一定であることと同値。
整数持ち上げ $`(l\oplus s)_j = l_j + s_j - 2 l_j s_j`$ を使うと、この一定性は $`\mathbb{Z}_{2^m}`$ 上の線形合同式系

$$\sum_j \theta_j\, s_j\, (1 - 2 l_j) \equiv 0 \pmod{2^m}$$

（全論理類代表 $`l`$・全 $`s \in \mathrm{rowspan}(H_X)`$ について）に帰着する。$`s \mapsto`$ 持ち上げは GF(2) 上で非線形なので **$`\mathrm{rowspan}(H_X)`$ の全 $`2^{r_X}`$ 元を列挙**して条件を張る（生成元だけでは不十分）。論理類代表も全 $`2^k`$ 類を回す。

解集合は、制約行列（成分 $`\in \lbrace -1,0,+1\rbrace`$）の整数対角化（Smith 標準形型の行・列基本変形）で厳密に求める（$`\theta`$ の総当たりはしない）。解 $`\theta`$ に対する論理位相は $`\varphi(l) = \sum_j \theta_j l_j \bmod 2^m`$（解の上では代表の取り方によらない）。

**判定**: 「真にレベル $`m`$ の対角論理ゲート（$`m=2`$ で論理 $`S`$、$`m=3`$ で論理 $`T`$、の奇数冪）が存在する」⟺ ある非自明論理類で $`\varphi`$ が奇数になる解 $`\theta`$ が存在する。解モジュールの生成元での $`\varphi`$ の値の gcd（と $`2^m`$ の gcd）が 1 かどうかで判定する。gcd が $`2^\nu`$ なら、レベル $`m`$ で達成できる論理位相は $`2^\nu`$ の倍数のみ（= 実質レベル $`m-\nu`$ のゲートまでしか出せない）。

arXiv:2602.14499 との関係: 論文はこの可否を持ち上げ（lifting）問題の障害写像（Bockstein 型準同型）の消滅として特徴づける（Thm IV.1 / Cor IV.2）。本プロトタイプは同じ可否を「論理性条件を直接 $`\mathbb{Z}_{2^m}`$ 上の線形合同式系として解く」直接判定で実装したもので、論文の各レベルでの判定（ガウス消去 / Smith 標準形で具体的に判定可能、という主張）の最小実装にあたる。

## ファイル

- `bockstein_check.py` — 判定本体（GF(2) 線形代数、整数対角化、mod $`2^m`$ 同次系ソルバ、`analyze`、総当たり検証 `verify_theta`）
- `codes.py` — 3 符号の定義と自己検査（$`H_X H_Z^{\mathsf{T}} = 0`$、$`[[n,k,d]]`$ を全列挙で検証）
- `test_known.py` — 既知事実との照合テスト（PASS/FAIL 出力、失敗時 exit 1）

## 実行方法

```
python codes.py        # 符号の自己検査のみ
python test_known.py   # 判定＋既知事実テスト（結果表を表示）
```

既知事実との照合（すべて再現）:

- **Steane: 横断的 $`S`$ 可・横断的 $`T`$ 不可**（arXiv:2602.14499 Cor V.1 の再現）。$`T`$ 不可は**非一様角度を許しても**成立（レベル 3 の解の論理位相がすべて偶数 = $`2\cdot\mathbb{Z}_8`$）。さらに $`\theta = 3\cdot 1_7`$（各量子ビットに $`S^\dagger`$）が論理 $`S`$ になることを総当たり検証で確認（Cor V.1 の具体解と一致）。
- **RM $`[[15,1,3]]`$: 横断的 $`T`$ 可**。$`\theta = 1_{15}`$（各量子ビットに $`T`$）で論理位相 $`7 \bmod 8`$（= 論理 $`T^\dagger`$）を総当たり検証で確認（古典的既知事実と一致）。
- **回転表面符号: 横断的 $`T`$ 不可**（既知）。**横断的 $`S`$ も不可**であることを確認（達成可能位相は $`2\cdot\mathbb{Z}_4`$、すなわち論理 $`Z`$ まで）。

副次的観察: Steane のレベル 3 の位相部分群が $`2\cdot\mathbb{Z}_8`$ であることは「レベル 3 の横断的ゲートで出せるのは高々論理 $`S`$（$`\omega_8^2 = i`$）まで」を意味し、レベル $`2\to 3`$ の持ち上げ障害（論文の $`\beta`$ 写像）の非消滅と整合する。

## 実装上の注意（理論の解釈で仮定した点）

1. 「横断的対角ゲート」は単一量子ビット対角ゲートのテンソル積 $`U(\theta) = \bigotimes_j \mathrm{diag}(1, \omega^{\theta_j})`$ に限定（論文の設定と同じ。CZ 等の多体対角は対象外）。
2. 「レベル $`m`$ のゲートが存在する」の判定基準は「ある非自明論理類の論理位相 $`\varphi`$ が奇数になる解の存在」とした（$`\varphi`$ が偶数のみなら $`\omega^{\varphi}`$ はより粗いレベルで実現できるため）。$`k=1`$ の 3 符号では非自明類は 1 つ。
3. 論理類の代表 $`l`$ の取り方に判定は依存しない（一定性条件の下で $`\varphi(l\oplus s) = \varphi(l)`$ となることを解の検証 assert で確認済み）。
4. 制約は生成元でなく $`\mathrm{rowspan}(H_X)`$ の全元・全論理類で張った（持ち上げの非線形性 $`a\oplus b = a + b - 2ab`$ のため。$`2^{r_X} \le 16`$ なので全列挙で厳密）。
5. 可と判定した場合は必ず、返された例 $`\theta`$ を線形代数を使わない総当たり位相列挙（`verify_theta`）で独立に検証している。
